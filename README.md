# ABC Bank AI-Powered Customer Support Chatbot

A Django web application that answers banking customer enquiries through
text or voice, in English or Hausa, using trained Machine Learning models
for intent classification and language detection.

## Features

- **Text & voice chat** — customers can type or speak; replies can be read
  back aloud (browser Speech Recognition / Speech Synthesis APIs).
- **Intent classification** — TF-IDF + Linear SVM model trained on 600
  labelled banking messages across 12 intents (94% test accuracy).
- **Language detection** — TF-IDF (character n-gram) + Linear SVM model,
  trained on the same dataset, detects English vs. Hausa (100% test
  accuracy).
- **Sentiment analysis** — lexicon-based classifier (Positive / Neutral /
  Negative); a Naive Bayes ML alternative was evaluated but is not used in
  production — see `chatbot/ai/evaluate_sentiment.py` for the comparison
  and reasoning.
- **Knowledge base** — bilingual question/answer pairs administrators can
  manage from a protected dashboard.
- **Admin dashboard** — chat history, feedback, unanswered queries, and
  usage analytics, all behind login.

## Tech stack

Python · Django · SQLite · scikit-learn · pandas · vanilla JS/CSS

## Setup

1. **Install dependencies**

   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Configure environment (optional for local dev)**

   The app runs out of the box with safe local defaults. For anything
   beyond localhost, set:

   ```bash
   export DJANGO_SECRET_KEY="your-own-secret-key"
   export DJANGO_DEBUG=False
   export DJANGO_ALLOWED_HOSTS="yourdomain.com"
   ```

3. **Set up the database**

   ```bash
   python manage.py migrate
   python populate_kb.py       # seeds the knowledge base
   python manage.py createsuperuser   # for the admin login
   ```

4. **Run the server**

   ```bash
   python manage.py runserver
   ```

   Visit `http://127.0.0.1:8000/` for the chatbot, and `/login/` to access
   the admin dashboard.

5. **Run tests**

   ```bash
   python manage.py test
   ```

## Retraining the ML models

Each model has its own training script, which prints accuracy and a
classification report before saving the model file:

```bash
python chatbot/train_model.py       # intent classification -> intent_model.pkl
python chatbot/train_language.py    # language detection -> language_model.pkl
python chatbot/train_sentiment.py   # sentiment (evaluation only) -> sentiment_model.pkl
```

Training data lives in `chatbot/datasets/`. To compare the rule-based and
ML sentiment approaches, run `python chatbot/ai/evaluate_sentiment.py`.

## Known limitations

- Sentiment analysis uses a rule-based approach in production because the
  labelled dataset (120 examples) is too small for the ML alternative to
  reliably outperform it — see the evaluation script above.
- Voice input/output for Hausa depends on the browser's speech engine;
  not all browsers ship a Hausa voice.
- This is a customer-support demo — it does not process real transactions
  (transfers, balance checks, etc.).
